
# Basic Bank System (v1)

A foundational Java implementation of a banking simulation demonstrating basic class interaction, data encapsulation, and transfer operations.

## Features
- **Account Management:** Create accounts with custom IDs and deposit funds.
- **Withdrawal Validation:** Secure withdrawal checks ensuring sufficient balance.
- **Fund Transfers:** Transfer money safely between two bank accounts.

## Classes Included
- `BankAccount.java`: Manages account balance, deposits, withdrawals, and validation.
- `Bank.java`: Handles transfer logic between accounts.
- `Main.java`: Simulates pre-lab transfer scenarios.
