
# Advanced Bank System (v2)

An advanced Object-Oriented Programming (OOP) extension featuring inheritance, polymorphism, method overriding, and specialized financial rules.

## Features
- **Inheritance Hierarchy:** `CheckingAccount` and `CommissionBank` extending core base classes.
- **Overdraft Limit:** Allows checking accounts to withdraw past their balance up to a specified limit.
- **Commission Processing:** Automatically calculates and accumulates service fees for the bank during transfers.
- **Visual Formatting:** Clean string formatting for clean console outputs.

## Classes Included
- `BankAccount.java`: Base class for standard accounts.
- `CheckingAccount.java`: Extended account supporting overdraft protection.
- `Bank.java`: Base bank logic.
- `CommissionBank.java`: Specialized bank applying transaction commission rates.
- `Main.java`: Runs complex lab scenarios and test cases.
